# Research presentation

Editable Quarto / reveal.js source for a roughly 10-minute research meeting.

Render with Quarto installed:

```sh
quarto render presentation/research-plan.qmd
```

Open `presentation/research-plan.html` in a browser. Press `S` for speaker notes. The loss curve is illustrative, not measured data. The names and translated research title were supplied by the user; the layout and sections draw on the supplied research-meeting example. The references slide is supplemental.
